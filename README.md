# 演唱会指南静态官网

将本目录完整上传到静态站点托管服务即可提供访问。页面、脚本和图片都使用相对路径，可从域名根目录或子目录提供服务，无需安装依赖或执行构建。

## 本地预览

从仓库根目录运行

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory site
```

打开 [本地官网](http://127.0.0.1:8080/) 查看首页。

- `index.html` 是首页，包含可以切换的实际界面预览、场馆出行和常见问题。
- `privacy.html` 是根据 App 的本机记录、分享和地图跳转整理的隐私说明。
- `assets/` 包含 App 图标、演出背景、场馆示意图和压缩的 App 界面截图。截图来源于项目现有的商店展示素材。

有正式域名后，可补充 Open Graph 分享图片的绝对地址。应用商店链接、联系信息和备案号在核实后按需加入。
